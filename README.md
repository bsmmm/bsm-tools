# BSM Tools

## العاب مدعومة :
- ريبلكا: كلمات لكل حرف (جماد، حيوان، اسم، نبات، دولة)، وتضغط على أي كلمة تنسخها.
- خمن: ترسل صورة إلى Google Lens عشان تعرف مكانها.
- اكس او: يقترح أفضل خطوة مع نسب الفوز.
